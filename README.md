# OpenAirAlert

OpenAirAlert is an open-source hyperlocal environmental intelligence and air quality alert platform built with Drupal.

The platform monitors live air quality sensor networks, calculates local environmental conditions, identifies hotspots, generates behaviour guidance, and sends alerts to subscribers through email and future messaging integrations.

## Features

- Local air quality monitoring
- Environmental intelligence dashboard
- Hotspot detection
- Behaviour guidance
- City-level monitoring
- Subscription alerts
- Email notifications
- Open-source architecture
- Drupal-based

## Current MVP Features

- AirGradient integration
- City monitoring
- PM2.5 analysis
- Behaviour recommendations
- Cron-based automated alerts
- Email alerts
- Environmental reporting dashboard

## Future Roadmap

- WhatsApp alerts
- SMS notifications
